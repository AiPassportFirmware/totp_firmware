# FoloTOTP —— TOTP 验证器应用

FoloTOTP 是本仓库的派生应用固件:可穿戴 TOTP(RFC 6238)验证器,带手势
密码、空闲锁定、Wi-Fi 配网与局域网远程密钥管理。它取代硬件测试演示成为
实际编译的固件;演示源码仅作为参考与宿主测试保留在仓库中。

## 功能总览

| 需求 | 行为 |
| --- | --- |
| 手势密码 | 首次开机设置 8 步"上/下"序列(2^8 = 256 种组合)。存储侧只保存加盐哈希(NVS),不保存序列本身。 |
| 空闲锁定 | 15 分钟无按键自动锁定,解锁需输入密码;连续输错 10 次锁定 60 分钟,锁定页提供倒计时显示。失败计数与惩罚截止时间持久化,断电重启不能绕过。 |
| Wi-Fi | SoftAP 网页配网(无需手机 App 与蓝牙),之后自动重连;SNTP 校时(TOTP 与惩罚计时都依赖正确时钟)。 |
| 语言切换 | 设备界面与远程管理网页跟随设备语言(默认简体中文)。**菜单 > 切换 English / 切换中文** 即时生效,选择持久化保存。 |
| 远程管理 | 联网后从菜单进入管理模式:屏幕显示 URL、该 URL 的二维码与随机 8 位数字码;同局域网设备打开 URL、输入数字码即可增删 TOTP 条目。 |
| 验证码显示 | 每 30 秒刷新并带倒计时进度条;UP/DOWN 翻页查看。 |

## Wi-Fi 配网

配网完全在设备端完成;凭证保存在本应用 NVS 命名空间,设备以 STA + DHCP 连接。

**菜单 > 无线网络 > 扫描连接**。

1. 设备扫描周围 2.4GHz 网络,列出信号最强的 8 个及其 RSSI。
2. 选中网络按确定,弹出两级键盘:第一级选择字符组(abc/ABC/123/符号)或
   直达动作(空格/退格/完成);第二级在组内滚动:上/下移动一个字符,长按跳
   5 位,确定录入当前字符并停在原位,最左"返回"项回到第一级。确定双击始终
   退格,确定长按始终完成连接(空密码直接连接开放网络)。
3. 设备经 DHCP 获取 IP,无线页面显示状态与 IP;密码错误会停止重试并显示状态。

凭证只保存在本应用的 NVS 命名空间。随时可从 **菜单 > 无线网络 >
清除凭证** 清除。

## 远程管理流程

1. 先连接 Wi-Fi(时间未同步前列表显示"等待时间同步",绝不在
   错误时钟下显示验证码)。
2. **菜单 > 远程管理**。屏幕显示 `http://<设备IP>/`、对应二维码与
   8 位数字码。
3. 局域网内任意设备扫码或输入 URL,填入数字码登录;页面列出全部条目,
   提供添加表单(名称、Base32 密钥、位数 6/8、周期 30/60 秒)与逐条删除。
4. 密钥对网络只写不读:服务端永不返回密钥或验证码。

管理模式在以下情况自动结束:设备端长按确定退出;设备锁定(15 分钟无操作
或手动锁定);网页会话 5 分钟无活动;连续输错 5 次数字码;Wi-Fi 断开。
会话期间,网页上的已认证操作不会刷新设备的空闲计时——设备仍会在 15 分钟
无按键后锁定。

## 名称与字符策略

设备端 UI 为简体中文,使用内置的 `app_font_sc_16` 子集渲染(思源黑体;
可打印 ASCII + GB2312 一级常用字 + 本应用固定文案,共 3872 个字形,
清单见 `assets/README.md`)。

条目名称接受 UTF-8(含中文):最多 24 字节(约 8 个汉字),不含控制字符,
设备端校验。字体覆盖集有限:SSID 或名称中超出覆盖集的生僻字会显示为
占位方框而不被拒绝。如需调整覆盖集,按 `assets/README.md` 记录的命令
重新生成字体并更新清单;参见
[中文字体清单](development/engineering/coding-conventions.md#chinese-fonts-and-missing-glyphs)。

## 安全说明与已知限制

- 手势密码按需求为 256 种组合,防"随手拿起看一眼",不防拥有无限时间与
  Flash 访问能力的攻击者。
- 管理服务为明文 HTTP,无 TLS。密钥虽不会经网络传输,也请在可信局域网使用。
- 惩罚截止依赖 SNTP 校时后的时钟;完全无法联网时设备保持锁定并提示等待
  校时(安全侧行为)。
- 每轮管理模式最多 5 次登录尝试,超过即关闭服务,需设备所有者重新开启。

## 实现模块

| 模块 | 职责 |
| --- | --- |
| `main/app_totp.c` | 纯逻辑:SHA-1/HMAC、HOTP、TOTP、Base32、条目序列化(宿主 RFC 向量测试) |
| `main/app_kb.c` | 纯逻辑:设备端 Wi-Fi 密码输入的三键滚动键盘模型 |
| `main/app_lock.c` | 纯逻辑:手势密码状态机、空闲锁定、60 分钟惩罚 |
| `main/app_store.c` | NVS 持久化 + 内存条目缓存(互斥保护) |
| `main/app_wifi.c` | STA/配网管理、重试、SNTP |
| `main/app_provision.c` | SoftAP 配网 HTTP 服务(扫描/连接/状态) |
| `main/app_server.c` | 远程管理 HTTP 服务(登录、会话、增删) |
| `main/app_ui.c` | 应用自有 LVGL 页面与 1 秒状态 tick |
| `main/app_main.c` | 启动顺序与按键分发 |
